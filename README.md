# Python for Data Science Practice
This repository contains practice codes from the "Python for Data Science" course offered by NPTEL. In this project, several data science operations are applied to datasets taken from Kaggle, focusing on data manipulation, visualization, and other core concepts learned during the course.

## Datasets
The following datasets from Kaggle were used in this project:

- car_sampled.csv: A dataset with car-related information.
- income.csv: A dataset containing income data.
- toyota.csv: A dataset with data related to Toyota vehicles.
## Operations Performed
This project includes the following data science operations:

- Data Loading and Preprocessing : Importing datasets using pandas.
Handling missing values, filtering, and basic cleaning.
- Data Exploration :
  Understanding the structure of datasets using functions like .head(), .info(), and .describe().
Using grouping and aggregation to summarize data.

- Data Visualization : Visualizing key insights from the datasets using libraries like matplotlib and seaborn.
Creating bar plots, histograms, scatter plots, and more.
- Pandas Operations : Sorting, filtering, and transforming data using pandas.
Merging and joining datasets.
Creating pivot tables and performing groupby operations.

## Learning Objectives
The purpose of this repository is to demonstrate and practice the following skills learned in the "Python for Data Science" course:

- Mastering basic to intermediate-level pandas operations.
- Applying data visualization techniques to identify trends and patterns in datasets.
- Performing real-world data manipulations using various Python libraries.
